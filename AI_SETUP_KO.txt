1. 먼저 실행
- ZIP을 압축 해제한 뒤 Start_ShortCompass.bat을 실행합니다.
- 브라우저는 http://127.0.0.1:8765/ShortsCompass.html 에서 사용합니다.
- 백업·설정 탭의 'AI 통합 작업실' 또는 이전 대본/A/B/장면 분석의 AI 버튼을 사용합니다. 모든 AI 제공자 요청은 로컬 도우미 서버를 경유합니다.

2. AI 제공자 연결
- OpenAI, Google Gemini, Anthropic Claude 중 하나를 선택합니다.
- 선택한 회사의 공식 개발자 콘솔에서 API 키를 발급하고, 본인 계정의 API 사용료·한도·접근 권한을 확인합니다.
- 모델 ID를 계정에서 사용할 수 있는 값으로 확인한 뒤 API 키를 입력하고 '키를 세션에 연결'을 누릅니다.
- 키를 연결한 후 작업 유형과 요청 내용을 입력해 실행합니다.
- 키는 로컬 서버 프로세스 메모리에만 저장됩니다. 서버를 종료하면 세션 키는 사라지고 다시 입력해야 합니다. 모델 이름은 사용자의 로컬 설정 폴더에 저장될 수 있지만 API 키는 설정 파일/백업/browser localStorage에 저장하지 않습니다. 기존 OpenAI/Gemini 대본·A/B·장면 분석 기능도 이제 로컬 프록시를 사용합니다.
- API 키는 타인에게 공유하거나 GitHub, 대본, 화면 캡처, 백업 파일에 넣지 마세요. 키가 노출되면 제공자 콘솔에서 폐기하고 새 키를 발급하세요.
- 각 제공자의 API는 ChatGPT/Claude/Gemini 유료 채팅 구독과 별도 과금일 수 있습니다. 테스트 전 사용 한도와 결제 설정을 확인하세요.


- '계정 모델 목록 가져오기'는 선택한 제공자의 공식 Models API를 호출합니다. 반환된 모델 목록은 해당 계정이 사용할 수 있을 가능성을 보여줄 뿐 생성 권한, 결제 상태, 지역 접근을 보장하지 않습니다. 목록에 없는 모델을 직접 입력해도 되지만 생성이 거부될 수 있습니다.
- '최소 생성 연결 테스트'는 짧은 실제 생성 요청을 보내 연결을 확인합니다. 토큰 사용료·할당량이 발생할 수 있습니다. 이 작업 환경에서 실계정 테스트를 미리 수행한 것은 아닙니다.
- '작업 유형에 맞춰 AI 자동 선택'은 설정된 작업별 우선순위로, 현재 연결된 제공자 중 하나를 고릅니다. 이는 벤치마크로 증명된 최고 모델 순위가 아닙니다. 실패 시 다음 제공자로 재시도하는 옵션은 기본 꺼짐이며, 켜면 실패한 요청도 과금될 수 있습니다.
- 영상 장면 분석은 사용자가 업로드한 영상에서 로컬로 추출한 최대 8장의 프레임을 선택된 AI 제공자에게 전송합니다. 개인/타인 소유의 민감 자료 및 권한 없는 영상은 보내지 말고, 업로드·분석 권한과 제공자의 데이터 정책을 먼저 확인하세요.

3. Windows 환경 변수 사용(선택)
현재 세션 메모리 키 대신 개인 PC의 환경 변수로 사용할 수 있습니다.
- Windows 검색에서 '환경 변수 편집'을 열어 사용자 변수에 OPENAI_API_KEY, GEMINI_API_KEY 또는 ANTHROPIC_API_KEY를 등록할 수 있습니다.
- 또는 PowerShell에서 setx OPENAI_API_KEY "본인의_키" 형태를 사용할 수 있습니다. 실제 키를 공유/로그/명령 기록에 남기지 않도록 주의하세요. setx는 이후 실행할 프로그램에 반영되므로 이미 열린 서버를 종료하고 다시 실행해야 합니다.
- 여러 제공자 키를 같은 PC에 넣을 필요는 없습니다. 사용하지 않는 키는 등록하지 마세요.
- 공용 PC나 타인의 Windows 계정에서는 사용하지 마세요. 환경 변수도 운영체제 사용자 프로필에 보관되므로 절대 무위험 저장소는 아닙니다.

4. 업데이트 자동 확인 설정
- 자동 업데이트 확인은 로컬 도우미 서버(Start_ShortCompass.bat으로 시작한 Python 프로세스)가 실행 중일 때 수행됩니다. 브라우저 탭을 닫아도 서버 콘솔 프로세스가 계속 실행 중이면 5분마다 설정/확인 조건을 점검합니다. 서버 프로세스가 종료되면 백그라운드 확인도 멈춥니다. 별도 Windows 서비스나 작업 스케줄러는 설치하지 않습니다.
- 이 배포 ZIP에는 제작자의 실운영 업데이트 피드가 설정되어 있지 않습니다. 따라서 다운로드 직후 원격 릴리스 자동 확인·다운로드는 작동하지 않으며, 관리자가 공개 릴리스/manifest를 실제로 구성해야 합니다.
- 업데이트를 배포할 관리자는 update_manifest.example.json을 참고해 본인이 관리하는 신뢰 가능한 GitHub 저장소에 update_manifest.json을 게시해야 합니다. manifest의 downloadUrl은 GitHub Release ZIP 파일을 가리켜야 하며 SHA-256은 게시할 ZIP의 실제 해시여야 합니다.
- 패키지는 현재 v2.38에서 허용된 최상위 파일만 포함하는 ZIP이어야 합니다. 하위 폴더를 ZIP 안에 넣지 말고, 최신 서버 버전·HTML 버전·manifest 버전이 모두 같아야 합니다.
- Windows에서 ZIP 해시는 다음 명령으로 구할 수 있습니다: certutil -hashfile 숏폼나침반_v2.38_AI모델라우팅보안개선.zip SHA256
- 실제 64자리 SHA-256 값을 manifest에 넣은 뒤 GitHub Release 최신 버전의 안정 URL `https://github.com/OWNER/REPOSITORY/releases/latest/download/update_manifest.json`을 업데이트 센터에 등록하세요. 매번 바뀌는 태그 URL 대신 `releases/latest/download` 경로를 사용합니다.
- 업데이트 확인은 무결성 검사·ZIP 경로 허용 목록·내부 버전 표기·백업 후 적용을 수행합니다. 선택적으로 '새 버전 자동 다운로드'를 켜면 검증 ZIP을 준비할 수 있지만 적용은 사용자의 명시적 확인 후 수행됩니다. SHA-256은 디지털 서명이 아니므로 본인이 신뢰하는 저장소와 배포자만 사용하세요. 자동 다운로드 실패는 같은 버전에서 최소 1시간 간격으로 재시도합니다.
- 잘못된 manifest나 업데이트 ZIP은 적용하지 않고 오류를 표시하도록 설계되어 있습니다. 배포자는 매 버전마다 오프라인 테스트 후 릴리스하세요.

[v2.38 AI 프록시 통합 및 모델 점검]
- 모델 카탈로그 API: OpenAI /v1/models, Gemini /v1beta/models, Anthropic /v1/models를 공식 HTTPS 호스트에 직접 요청합니다. 인증 요청은 리디렉션을 거부하고 모델 목록 응답에는 API 키를 절대 포함하지 않습니다. Gemini 목록은 계정이 반환한 생성 지원 모델로 필터링합니다.

- 프록시에서는 JPEG/PNG/WebP MIME과 실제 바이트 서명을 검사하고 이미지 장수·개별 크기·합계 크기를 제한합니다. 선택한 제공자에게 보내기 전에 로컬 입력값을 검증하지만, 전송 자료는 제공자 약관에 따라 처리됩니다.
- 검증: Test_ShortCompass.py + Test_UpdateAndAI.py 총 75개 통과. 실제 외부 AI API/계정 모델 목록 호출은 사용자 키가 없어 미수행입니다.
