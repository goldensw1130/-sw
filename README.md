# 숏폼 나침반

Windows용 숏폼 콘텐츠 조사·제작·성과분석 도구입니다.

## 현재 초기화 절차

이 저장소는 v2.42 초기 배포 패키지로 자동 릴리스 환경을 구성합니다. 최초 커밋 단계에서는 패키지를 작은 Base64 조각으로 보관해 GitHub API를 통한 안전한 초기화를 진행합니다. 최초 GitHub Actions 실행은 아래를 수행합니다.

1. 조각의 순서를 확인하고 ZIP을 재구성합니다.
2. 예상 SHA-256 `348224f61c6713ce64e1b01d7b00cd994285995ac68f73502bb39d88ef78cbec`와 ZIP 경로 안전성을 검증합니다.
3. Python 및 JavaScript 회귀 테스트를 실행합니다.
4. 실제 소스 파일을 저장소 루트로 복원하고 임시 Bootstrap 조각을 제거합니다.
5. 버전 태그와 소스 버전이 일치할 때에만 `ShortCompass-v2.42.zip`, `update_manifest.json`, `SHA256SUMS.txt`를 GitHub Release로 게시합니다.

## 자동 릴리스

- `main`의 앱 소스 변경: 앱의 `APP_VERSION`에 해당 릴리스가 아직 없으면 테스트 후 릴리스를 생성합니다.
- `vX.YY` 태그 push: 태그와 앱 소스 버전이 같을 때 릴리스를 생성합니다.
- Actions 탭에서 수동 실행: 버전을 직접 지정하거나 현재 소스의 버전을 사용합니다.
- 같은 버전을 이미 게시했으면 실패 처리합니다. 새 릴리스 전에 앱 버전, HTML 제목·푸터 및 백업 메타데이터를 함께 올려야 합니다.

## 앱 실행

Windows에서 `Start_ShortCompass.bat`을 실행하세요. 외부 AI API를 사용하려면 본인 계정의 API 키와 별도 사용량 한도가 필요합니다.

## 보안

API 키·개인 토큰·개인키를 소스/릴리스에 커밋하지 마세요. 업데이트 패키지는 SHA-256으로 검증되지만, 이는 GitHub 계정이나 저장소 접근권한을 대체하지 않습니다. 플랫폼 정책 준수와 수익을 보장하지 않습니다.
