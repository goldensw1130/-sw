# 숏폼 나침반

Windows용 숏폼 콘텐츠 조사·제작·성과분석 도구 및 자동 릴리스 저장소입니다.

- 저장소: https://github.com/goldensw1130/-sw
- 최신 버전: v2.47
- 릴리스: https://github.com/goldensw1130/-sw/releases/tag/v2.47

## Windows 실행
1. 공식 Release ZIP 전체를 새 폴더에 압축 해제합니다.
2. `Start_ShortCompass.bat`을 실행합니다. 로컬 서버 `/health` 응답 후 브라우저가 열립니다.
3. 서버 창은 검색, AI 프록시, 업데이트 기능을 이용하는 동안 닫지 마세요.
4. 시작 실패 로그: `%LOCALAPPDATA%\ShortCompass\logs\start-shortcompass.log`

릴리스 ZIP은 모든 BAT 파일에 CRLF 줄바꿈을 적용하며, 자동 테스트가 이를 검증합니다. 공개 저장소 소스에는 API 키나 사용자 개인정보를 올리지 마세요.
