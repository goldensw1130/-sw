숏폼 나침반 v2.45 GitHub 자동 릴리스 설정 진단 핫픽스

- Windows PowerShell 5.1에서 GitHub 저장소 파일 목록을 확인할 때 발생할 수 있는 `function not defined: blob/0` 오류를 수정했습니다.
- `gh api --jq`의 문자열 필터 대신 원본 JSON 응답을 PowerShell에서 해석해 저장소 파일 목록을 검사합니다.
- 기존 저장소의 예상치 못한 파일이나 숏폼 나침반 코드 덮어쓰기 방지 검사는 유지합니다.
- 앱 기능과 앱 버전 v2.45는 변경하지 않았습니다. 이 패키지는 자동 릴리스 설정 스크립트 수정본입니다.
