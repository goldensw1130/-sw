[v2.20 공식 TikTok Research API 선택 기능]
TikTok Research API 접근이 승인된 프로젝트를 보유한 경우에만 사용할 수 있습니다. 앱의 TikTok 검색 패널에서 Client Key/Secret, 키워드, 지역, 시작일/종료일을 입력하고 '공식 API 검색 · 조회수순'을 누릅니다. 인증 정보는 저장하지 않으며 요청 후 Secret 입력란을 비웁니다. 날짜 범위는 최대 30일이고 응답은 최대 100개입니다.
승인된 Research API 프로젝트가 없다면 기존 공개 웹 색인 검색을 사용하세요. 일반 검색엔진 결과는 조회수를 제공하지 않으므로 조회수 높은 순 자동 정렬이 불가능합니다. Research API 승인 조건과 사용 목적은 TikTok 공식 개발자 포털에서 확인하세요.


[v2.20 공식 Research API 결과 수]
- TikTok Research API 승인 프로젝트가 있는 경우 결과 수를 100~500개 범위에서 선택할 수 있습니다.
- API는 페이지당 최대 100개씩 순차 조회하며, 전체 결과를 조회수 높은 순으로 다시 정렬합니다.
- 200개 이상을 선택하면 여러 API 요청이 발생하므로 필요한 경우에만 큰 값을 사용하세요. 실제 사용 가능 여부는 TikTok Research API 승인과 권한에 달려 있습니다.


[v2.21 조회수 변화 추적]
공식 Research API 검색 결과를 성공적으로 받으면 영상별 통계 스냅샷을 로컬 브라우저 저장소에 기록합니다. 같은 영상이 다음 검색에도 포함되면 이전 확인 시점과 현재 응답의 조회수 차이를 보여 줍니다. 첫 검색에는 비교 기록이 없으므로 '이전 기록 없음'이 표시됩니다. CSV 내보내기에는 현재/이전 조회수, 변화량, 확인 시각이 포함됩니다. 기록은 브라우저 프로필에 저장되며 최대 500개 영상, 영상별 20회 기록으로 제한됩니다.

[v2.22 스마트 검색 안정화]
- 같은 검색어를 반복 실행하면 최근 결과를 잠시 재사용해 불필요한 외부 요청을 줄입니다.
- 네트워크 연결 실패나 검색엔진 차단은 캐시하지 않으므로 진단 후 다시 시도할 수 있습니다.
- 공식 Research API의 조회수 정렬은 쉼표가 포함된 숫자 문자열도 숫자로 비교합니다.
- 검색 결과 캐시는 최대 3분이며 로컬 메모리에만 존재하고 앱을 종료하면 사라집니다.

[v2.25 백업 안정성 개선]
- 전체 백업 파일은 앱 버전과 내보낸 시각을 함께 기록합니다. 이전 버전의 백업도 가져올 수 있습니다.

- 복구 중 중복 TikTok 표본은 제외되며, 새 표본 등록 때도 중복을 안내합니다.
- 중요한 자료는 업데이트 전후로 전체 백업을 별도로 보관하세요. 브라우저 로컬 저장소는 브라우저 초기화·프로필 변경·기기 변경 시 사라질 수 있습니다.


[v2.26 아웃라이어 탐색]
TikTok 표본 입력에서 '채널 평소 조회수 중앙값'을 선택 입력할 수 있습니다. 해당 영상 본인을 제외한 계정의 최근 영상 5~10개 조회수 중앙값을 입력하면 '채널 평소 대비 초과 성과 배수'가 계산됩니다. 예를 들어 대상 영상 120,000회, 평소 중앙값 10,000회라면 12배입니다. 표본 목록의 정렬 메뉴에서 이 값을 기준으로 정렬할 수 있고 CSV에도 내보낼 수 있습니다. 채널의 일반적인 성과를 기준으로 한 비교값이며, 조회수의 미래 증가나 플랫폼 전체 순위를 뜻하지 않습니다.


[v2.27] 조회수 추적 및 중복 관리 개선

4. 7일 실행 루틴을 따라 수요 확인부터 결과 측정까지 진행합니다. 기록은 전체 JSON 백업에 포함됩니다.

주의: 실제 확인된 수익만 기록하고, 표본이 적을 때는 결론을 단정하지 마세요.


[v2.32 후킹·CTA A/B 비교 실험실]
1. 수익화 실험실에서 “후킹·CTA A/B 비교 실험실”을 엽니다.
2. 실험 이름과 비교할 변수 하나를 선택하고 가설을 기록합니다.
3. A안과 B안의 실제 후킹 문구/CTA, 게시일, 조회·클릭·전환·확정 수익을 입력합니다. 게시 후 수치가 쌓이면 “수치 입력 / 수정”으로 갱신합니다.
4. 조회→클릭률, 클릭→전환율, 조회 1,000회당 확정 수익 중 하나를 선택해 결과를 비교합니다.
5. A/B 결과 CSV를 저장해 엑셀 등에서 장기적으로 분석할 수 있습니다.
주의: 양쪽 조회수 1,000회 이상, 게시 후 72시간 경과 여부는 성급한 결론을 줄이기 위한 운영상 참고선입니다. 통계적 유의성이나 인과관계를 증명하지 않으며, 게시 시간·유입·영상 길이 등 조건을 가능한 한 비슷하게 맞추세요. 실제 확정 수익만 입력하세요.


[v2.33 실험 신뢰도 점검]
1. A안과 B안의 게시일 및 성과 확인일을 입력합니다. 성과 확인일은 현재 입력한 조회·클릭·전환·확정 수익을 실제로 확인한 날짜입니다.
2. 비교 카드의 품질 경고에서 조회수·클릭·전환 분모, 조회량 차이, 게시 시점, 관찰 기간 차이를 확인합니다.
3. 클릭률/전환율의 Wilson 참고 범위가 겹치거나 B-A 참고 범위에 0이 포함되면 승자를 단정하지 말고 비슷한 조건으로 반복 실험합니다.
4. 이 구간은 통계적 유의성 검정이 아니며, 게시 시간·추천 알고리즘·시청자 집단 등 혼입 요인을 제거하지 않습니다. 실제 플랫폼 성과는 자동으로 수집하지 않습니다.
5. 수익 지표는 개별 영상 1개만으로 판단하지 말고 유사 조건의 여러 게시물과 실제 정산 확정 수익을 비교합니다.


[v2.34 출처와 실적 반영 순위]
- YouTube API 기반 영상 검색·분야 분석에는 출처, 검색 조건, 수집 시각이 표시됩니다. 수집 시각은 API를 요청한 시각이며 플랫폼 내부 통계 갱신 시각과 같다는 보장은 없습니다.
- 소재 리스트 CSV는 출처 제공자·검색어·수집 시각·지역·기간을 포함합니다. TikTok Research API 저장 목록/CSV에는 공식 출처, 검색 지역·기간, 페이지 수와 수집 시각이 포함됩니다.
- 공개 웹 색인 검색은 링크 탐색용으로만 사용합니다. 조회수·좋아요 등의 통계를 자동으로 얻는 것이 아닙니다. 캐시 결과에는 최초 수집 시각과 현재 응답 시각을 구분합니다.
- 수익화 후보의 실적 반영 보조 순위는 같은 플랫폼과 수익 경로에서 후보 3개 이상, 후보마다 실험 3회 이상·조회 3,000 이상·클릭/문의 30건 이상일 때만 활성화됩니다. 조건을 충족하지 못하면 기본 평가 점수가 그대로 사용됩니다. 비교 지수는 미래 수익을 예측하지 않습니다.


[v2.34 지표 입력 상태 확인]
- 실제로 0회/0건/0원을 확인했다면 숫자 0을 입력합니다. 확인하지 못했거나 알 수 없는 값은 빈칸으로 둡니다.
- 수익화 실험 카드에서 조회수·클릭/문의·전환·확정 수익 각각의 입력 상태를 확인합니다. 빈칸의 기본 표시값 0은 실제 0과 다르며 분석 점수에 포함되지 않습니다.
- 요약 합계는 확인 입력된 지표만 반영합니다. 이전 버전 기록은 입력 상태를 알 수 없으므로 실적 기반 순위에서 제외됩니다. 필요한 경우 기존 실험을 확인 후 다시 기록하세요.
- 출처 수집 시각은 데이터를 요청/수신한 시각이며 플랫폼 내부 통계의 마지막 갱신 시각을 뜻하지는 않습니다.


[v2.35 검색 실패 해결하기]
- '검색엔진 제한'은 네트워크 연결이 되어 있어도 검색 서비스가 요청을 제한한 상태일 수 있습니다. 이때 앱은 CAPTCHA나 제한을 우회하지 않습니다.
- '결과 없음'은 공개 웹 색인에서 해당 영상 링크를 찾지 못했다는 뜻이며, TikTok 안에 영상이 없다는 뜻은 아닙니다. 검색어를 줄이거나 외부 검색 링크를 열어 확인하세요.
- '로컬 서버 연결 실패'는 외부 검색엔진 오류와 구분됩니다. Start_ShortCompass.bat 실행 상태와 127.0.0.1:8765 연결을 확인하세요.
- 검색 품질 기록에는 전체 응답 시간, 제공자별 상태, 캐시 사용 여부가 남습니다.
- 공개 웹 색인 검색은 조회수를 제공하지 않습니다. 조회수 높은 순 자동 검색은 승인된 공식 API 결과에 한해서만 지원합니다.


[v2.36 YouTube 조회수 정렬 개선]
1. ‘YouTube 실시간 검색 · 조회수 확인’에서 검색어를 입력하고 결과 개수를 5~50개 중 선택하세요.
2. ‘조회수 높은 순’은 YouTube 검색 API 결과를 가져온 뒤 실제 viewCount 통계로 다시 정렬합니다. 상세 응답 순서가 달라도 순위 표시가 흔들리지 않도록 했습니다.
3. ‘게시 후 추정 조회수/일’은 최신 게시 순으로 가져온 요청 표본 안에서 누적 조회수를 게시 후 경과일로 나누어 재정렬합니다. 최근 24시간의 실제 증가량은 아닙니다.
4. ‘검색 결과 CSV 내보내기’로 순위·제목·채널·URL·조회수·게시일·추정 조회수/일·검색 조건·수집 시각을 저장할 수 있습니다.
5. 정렬은 요청한 최대 50개 표본 내에서만 적용됩니다. YouTube 전체 영상의 절대 순위나 Shorts 전체 피드의 대표 순위가 아닙니다. API 키, API 활성화, 할당량 및 인터넷 연결이 필요합니다.
