[v2.49] 콘텐츠 제작 흐름 대시보드 설계

- 대시보드에 소재 발굴·소재 검토·대본 제작·성과 학습의 4단계 진행 보드를 추가했습니다.
- 저장된 소재/대본/게시 성과에서 실제로 확인 가능한 값만 계산합니다. 게시 성과가 입력되지 않은 항목은 완료로 간주하지 않습니다.
- 단계 카드를 눌러 기존 화면으로 이동할 수 있으며, 기존 검색·대본·성과·백업 기능은 유지합니다.
- 데스크톱·태블릿·모바일 대응, 키보드 포커스, 진행률 접근성 표시, 동작 감소 설정을 반영했습니다.
- 배포 ZIP에 포함되는 BAT 파일의 CRLF 줄바꿈과 BOM 유무를 회귀 테스트로 확인합니다.

[v2.48] Windows 서버 실행 오류 오판 수정

- 서버 콘솔을 여는 START 명령 직후 기존 ERRORLEVEL을 확인해 실패로 오판하던 코드를 제거했습니다.
- /health 정상 응답을 기준으로 시작 성공 여부를 판단합니다.
- 서버가 정상 시작하면 브라우저를 열고 임시 시작 창은 닫아, 실행 중인 서버 창만 남깁니다.
- 배포 ZIP 내부 .bat 파일은 CRLF 줄바꿈 및 UTF-8 코드페이지 초기화를 유지합니다.

[v2.48] Windows BAT 실행 오류 수정

- Windows CMD에 맞게 릴리스 ZIP 내 .bat 파일을 CRLF 줄바꿈으로 정규화합니다.
- Start_ShortCompass.bat의 복잡한 FOR /F + PowerShell 명령 치환을 없애고 단순한 상태 코드 방식으로 변경합니다.
- 서버를 별도 콘솔에서 실행하고 /health 응답이 확인된 이후 브라우저를 엽니다.
- 시작 실패 시 서버 콘솔 및 진단 로그를 유지합니다.
